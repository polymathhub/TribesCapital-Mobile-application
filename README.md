# Tribes Capital — Flutter UI Prototype

A clean Flutter implementation of the Tribes Capital iOS-style community dashboard.

## Navigation
The bottom navigation now follows the supplied reference:
- One dark rounded pill container.
- Five evenly spaced destinations: Home, Search, Offers, Cart, Profile.
- Only the active destination expands into a white pill.
- Inactive destinations show icons only.
- Tapping an item switches the active page.

## Included
- iOS-style rounded cards and spacing
- Community overview
- Investments
- Upcoming events
- Swipeable Insights & News carousel
- Community activity
- Working bottom navigation

## Run in VS Code
Open this folder in VS Code, then use **Terminal → New Terminal**:

```bash
flutter pub get && flutter run
```

For iOS, start/select an iPhone Simulator and run the same command.
